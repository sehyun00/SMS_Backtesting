# 논문 업데이트 스킬

이 스킬은 학술 논문을 업데이트할 때 일관성, 기술적 정확성, 그리고 학술적 표준(IMRaD 구조)을 준수하기 위한 가이드라인과 모 범 사례를 제공합니다.

## 1. 핵심 원칙

- **데이터 기반 정확성**: 결과를 절대 지어내지 마세요(Hallucination 금). 모든 정량적 주장(MSE, Sharpe Ratio 등)은 반드시 제공된 결과 파일(CSV, 로그)에 근거해야 합니다.
- **코드-모델 일치**: "방법론(Methodology)" 섹션은 실제 코드 구현을 엄격하게 반영해야 합니다. 코드가 `AdamW`를 사용하는데 논문이 `SGD`라고 되어 있다면, 논문을 업데이트하세요.
- **격식 있는 학술적 어조**: 객관적이고 격식 있는 언어를 사용하세요. 1인칭 단수("I")를 피하고, 학회 성격에 맞게 "We"나 수동태를 선호하세요.

## 2. 섹션별 가이드라인

### 초록 (Abstract)

- **마지막에 업데이트**: 항상 결과(Results)와 결론(Conclusion)을 마친 후에 초록을 업데이트하세요.
- **핵심 요소**: 문제 -> 방법(TGNN+DDPG) -> 주요 결과(MSE -31%, Sharpe 1.01) -> 시사점.

### 방법론 (Methodology) (제안 모델)

- **수식 <-> 코드**: 수학적 공식은 코드 로직과 일치해야 합니다.
  - *예시*: 만약 `combined_loss = mse + lambda * contrastive`라면, 방정식도 두 항을 모두 보여주어야 합니다.
- **다이어그램**: 아키텍처가 변경되면 Mermaid 다이어그램을 업데이트하거나 그림을 참조하도록 제안하세요.

### 실험 설계 (Experimental Design)

- **하이퍼파라미터**: `config.yaml`을 확인하세요. 논문의 표 3(하이퍼파라미터)은 `config.yaml`과 정확히 일치해야 합니다.
- **데이터셋**: `main.py`나 `data_loader.py`를 참조하여 데이터 기간(Train/Test 분리 날짜)을 검증하세요.

### 결과 (Results)

- **비교 표**: 결과를 업데이트할 때, 기준 모델(LSTM, Transformer)들이 *동일한 테스트 셋*에서 공정하게 비교되고 있는지 확인하세요.
- **통계적 유의성**: p-value나 t-test 결과가 있다면 포함하세요.
