# 코드 마이그레이션 워크플로우

1.  **대상 식별**: 레거시 코드에서 마이그레이션할 파일이나 모듈을 결정합니다.
2.  **스킬 로드**: `view_file`을 사용하여 `.agent/skills/research_code.md`를 읽고 필수 표준을 파악합니다.
3.  **소스 읽기**: 레거시 파일의 내용을 읽습니다.
4.  **리팩토링 및 작성**:
    -   `new/src/...` 경로에 해당하는 파일을 생성합니다.
    -   **중요**: 절대 복사-붙여넣기 하지 마세요. 다음 규칙에 맞춰 **재작성**해야 합니다:
        -   Type Hint 추가.
        -   하드코딩된 값 제거 (Config 사용).
        -   적절한 Docstring 추가.
        -   모듈화 보장.
5.  **검증**: 새 코드가 올바르게 import 되고 문법 오류가 없는지 확인합니다.
