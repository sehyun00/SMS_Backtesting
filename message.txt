## 🔍 CRRA만 적용된 거야?

**아니요!** CRRA만 있는 게 아닙니다. 총 **6개의 핵심 요소**가 함께 작동합니다.

***

## 📋 적용된 6가지 요소

### 1. CRRA 효용함수 (주 보상) ⭐

```
공식: Reward = -1 / (1 + net_return)
역할: 위험회피 투자자 효용 반영
효과: 손실에 더 큰 페널티
```

***

### 2. 거래비용 (Transaction Cost) ⭐

**코드**: `run_comparison.py` Line 131-135

```python
turnover = sum(|new_weight - old_weight|)
cost = turnover × 0.05% (5bps)
net_return = portfolio_return - cost
```

**예시**:
- 비중 변경: NVDA 30%→35%, AMZN 25%→28%, ...
- Turnover: |5%| + |3%| + ... = 15%
- 비용: 15% × 0.05% = **0.0075%**

**효과**: 과도한 리밸런싱 억제 (너무 자주 거래하면 비용으로 손해)

***

### 3. Softmax 정규화 ⭐

**코드**: `model.py` Line 45

```python
scores = self.global_net(x)
weights = F.softmax(scores, dim=-1)
```

**처리**:
```
입력 점수: [3.2, 1.5, 4.1, 2.0, ...]
  ↓ Softmax
출력 비중: [0.28, 0.12, 0.35, 0.15, ...]  # 합=1.0
```

**효과**: 자연스러운 분산투자 유도, 극단적 비중 방지

***

### 4. Exploration Noise (탐색 노이즈) ⭐

**코드**: `model.py` Line 98-104

```python
noise_std = max(0.01, 0.2 - episode * 0.002)
# 초반 20% → 점차 감소 → 최종 1%
```

**학습 단계**:
- 초반 (Episode 1-50): **20% 노이즈** → 다양한 전략 탐색
- 중반 (Episode 50-80): **10% 노이즈** → 유망 전략 집중
- 후반 (Episode 80-100): **1% 노이즈** → 미세 조정
- 테스트: **0% 노이즈** → 최적 전략만 사용

**효과**: 탐색-활용 균형, 로컬 최적해 탈출

***

### 5. Target Network Soft Update ⭐

**코드**: `model.py` Line 150-151

```python
θ_target ← 0.001 × θ_main + 0.999 × θ_target
# τ = 0.001 (0.1%씩 천천히 업데이트)
```

**설명**:
- Target Network는 Q-Value 계산 시 '정답' 역할
- Main Network보다 1000배 느리게 업데이트
- Moving Target 문제 해결

**효과**: 학습 안정화, 과적합 방지

***

### 6. LayerNorm (레이어 정규화) ⭐

**코드**: `model.py` Line 12, 14

```python
nn.Linear(num_features, hidden_dim),
nn.LayerNorm(hidden_dim),  # ← 각 레이어 출력 정규화
nn.ReLU(),
```

**설명**: 각 레이어 출력을 평균 0, 분산 1로 정규화

**효과**: 
- Gradient 안정성 향상
- 학습 속도 증가
- 깊은 네트워크 학습 가능

***

## 🔄 전체 작동 흐름

```
Step 1: Actor → 포트폴리오 비중 제안
        ↓ (Softmax 정규화 적용)

Step 2: 시장 → 수익률 계산
        portfolio_return = 8.84%

Step 3: 거래비용 차감
        cost = 0.0075%
        net_return = 8.8325%

Step 4: CRRA 보상 계산
        reward = -0.9189

Step 5: Critic → Q-Value 학습
        target_q = reward + γ × next_q
        (LayerNorm 적용)

Step 6: Actor → Q-Value 최대화
        (+ Exploration Noise 추가)

Step 7: Target Network 업데이트
        (천천히 안정적으로)
```

## 💎 요약

| 요소 | 역할 | 효과 |
|------|------|------|
| **1. CRRA** | 주 보상 함수 | 위험회피, 손실 페널티 |
| **2. 거래비용** | 비용 차감 | 과도한 리밸런싱 억제 |
| **3. Softmax** | 비중 정규화 | 자연스러운 분산투자 |
| **4. Noise** | 탐색 유도 | 탐색-활용 균형 |
| **5. Target Network** | 학습 안정화 | 과적합 방지 |
| **6. LayerNorm** | Gradient 정규화 | 학습 속도 향상 |

**결론**: CRRA만 있는 게 아니라, **6개 요소가 협력**해서 안정적이고 현실적인 투자 전략을 학습합니다!
