research_code 스킬의 학술 연구 표준(재현성, 강건성, 모듈화)을 준수하며 코드를 수정합니다.

**대상 파일**: $ARGUMENTS

## 전제 조건
먼저 `.agent/skills/research-code/SKILL.md` 파일을 읽어 전체 연구 코드 품질 표준을 확인하세요.

## 단계

### 1. 컨텍스트 분석
- 수정할 대상 파일을 읽습니다.
- **Config 의존성 확인**: 하드코딩된 값(Learning Rate, 차원 수 등)이 있다면 `config.yaml` 참조로 변경할 것을 계획합니다.
- **Type Hint 점검**: 함수의 인자와 반환값에 타입 힌트가 누락되어 있는지 확인합니다.

### 2. 수정 계획 수립
- **기능 동등성(Functional Parity)**: 리팩토링의 경우, 입력에 대한 출력이 기존과 수학적으로 동일한지 검증합니다.
- **재현성(Reproducibility)**: `random`, `torch` 등의 시드 고정 로직이 보존되는지 확인합니다.
- **200줄 규칙**: 파일이 너무 커지면 분리를 제안합니다.

### 3. 코드 수정
- 변경된 함수나 클래스에 명확한 Docstring을 작성합니다.
- 중요한 로직 변경에는 근거(Rationale)를 주석으로 남깁니다.

### 4. 검증
- 편집 후 Lint 에러가 없는지 확인합니다.
- 필요 시 관련 테스트 코드를 실행하거나, `check_models.py`와 같은 검증 스크립트를 실행합니다.
