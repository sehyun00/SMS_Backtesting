## 2. 모델 구조

```
입력 데이터 (OHLCV + Fama-French 5-Factor)
        │
        ├──▶ [Path A] TGNN (Temporal Graph Neural Network)
        │       Linear Projection → GCN×2 (128→128→64)
        │       → Multi-Head Temporal Self-Attention (4-head)
        │       → 종목별 임베딩 (96-dim: GCN 64 + Macro MLP 32)
        │       → Softmax → TGNN 포트폴리오 비중
        │
        └──▶ [Path B] DDPG (Deep Deterministic Policy Gradient)
                SharedFactorEncoder (64-dim) → Actor → DDPG 포트폴리오 비중

                    ↓
            [Ensemble Network]
            alpha = sigmoid(Linear(tgnn_emb + ddpg_emb + scores))
            alpha ∈ [0.1, 0.9]  (고정 alpha 모드)

            final_weights = α × TGNN_weights + (1-α) × DDPG_weights
```

- **TGNN**: 종목 간 그래프 관계 + 시간적 패턴을 동시에 학습
- **DDPG**: RL 기반 포트폴리오 정책 최적화 (Actor-Critic)
- **Hybrid Ensemble**: 두 모델의 출력을 동적 alpha로 혼합

```

  copying shape torch.Size([128, 138]) from checkpoint,
  current model expects torch.Size([128, 170])
```

- 원인: `agent.py`에서 `tgnn_emb_dim = 96`으로 하드코딩

  - 결과: Hybrid 앙상블이 **랜덤 가중치**로 동작 → 전략 완전히 망가짐
- 수정: `tgnn_emb_dim`을 `use_factors` 여부에 따라 동적으로 계산

### [2026-03-31 오전] 근본 원인 분석

**원인 1 — DDPG Critic Q-value 과대추정**

DDPG 훈련 중 loss가 양수 → 깊은 음수로 지속 하락:
```
Epoch 0:   Loss: +0.088
Epoch 100: Loss: +0.010
Epoch 200: Loss: -0.060
Epoch 500: Loss: -0.412
Epoch 800: Loss: -0.943
```
Loss = `-Q_value`. Loss가 낮아진다 = Critic이 "이 포트폴리오가 매우 좋다"고 판단. 하지만 실제 백테스트 결과는 전 구간 벤치마크 하회. **Critic이 훈련 데이터에 과적합 (Q-value 과대추정)**.

**DDPG 단독 성과**:

| 전략 | CAGR | vs Benchmark (6.35%) |
|------|------|----------------------|
| DDPG_Monthly | -2.23% | -8.58%p |
| DDPG_Quarterly | +0.49% | -5.86%p |
| DDPG_Semiannual | -5.05% | -11.40%p |
| DDPG_Annual | +3.08% | -3.27%p |

**4개 주기 전부 벤치마크 하회.** 독립적인 성과 모델로서 기능하지 못함.

**원인 2 — Dynamic Alpha가 불안정성을 증폭**

기존 구조:
```python
# 주기별 다른 alpha 학습 (Horizon-Aware Dynamic Alpha)
horizon_emb = self.horizon_embedding(horizon_tensor)  # 0~3
ensemble_loss = -Q_value.mean()   # DDPG Critic으로 alpha 학습
alpha_reg = 0.01 * (...)          # 정규화 계수 0.01 → 너무 약함
```

인과관계:
1. DDPG Critic이 seed마다 다른 Q-value로 수렴
2. alpha를 Critic으로 학습 → seed마다 alpha 방향이 달라짐
3. Annual은 테스트 기간(2021~2025) 리밸런싱 4~5번뿐
4. alpha 한 번 잘못 결정 → 연간 수익률 전체 역전

**Monthly/Quarterly가 상대적으로 안정적인 이유**: 48번/16번 리밸런싱 → 잘못된 alpha가 희석됨.

### [2026-03-31] 모델 안정화 수정 적용

**수정 1 — `config.yaml`**
```yaml
# 변경 전
hybrid_alpha_mode: "dynamic"   # horizon별 다른 alpha

# 변경 후
hybrid_alpha_mode: "fixed"     # 단일 content-based alpha
```

**수정 2 — `src/models/hybrid/agent.py`**
```python
# 변경 전
alpha_reg = 0.01 * ((alpha - 0.5) ** 2).mean()

# 변경 후 — 10배 강화
alpha_reg = 0.1 * ((alpha - 0.5) ** 2).mean()
```

**논문 처리 방향**:
- Monthly, Quarterly를 메인 결과로 보고 (전 seed 플러스, 벤치마크 상회)
- Semiannual, Annual은 Limitation 섹션에서 "DDPG 불안정성으로 인한 장기 리밸런싱 불안정" 으로 명시
- Dynamic Alpha는 "향후 TD3/SAC 기반 안정적 Critic 확보 후 재도입" 방향 제시

## 7. 향후 개선 방향 (제출 이후)

- **TD3 (Twin Delayed DDPG) 교체**: DDPG의 Q-value 과대추정 문제를 구조적으로 해결한 알고리즘. 코드 변경 범위는 DDPG agent 파일 1개 (~100줄). 안정적인 Critic 확보 후 Dynamic Alpha 재도입 가능.
- **테스트 종목 확대**: 현재 10종목 → 30종목으로 확장 시 결과 일반화 가능성 증가
- **Statistical Significance 검증**: Bootstrap CI, t-test로 벤치마크 대비 유의성 수치화
